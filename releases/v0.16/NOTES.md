# Caduceus for OM-3 v0.16

- Hue, Light and WB/BW pages for COLOR 1–4, saved to `OM3MOD/BUNDLES.BIN`.
- Profile bank: 5 profiles per COLOR in `OM3MOD/PROFILES.BIN`, Profiles page dial 0–5.
- Card files: `GUIDES.BIN` (page labels). `NAMES.BIN` is ignored by this version (labels say "Profiles").
- Camera-tested.

Make it: run the launcher and type `v0.16` (or `python3 firmware/patch.py --release v0.16`). The files here are the patch (only the bytes Caduceus for OM-3 adds; no OM firmware), the page labels and the expected checksums.
